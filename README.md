### Hi, I'm Brian 👋

I'm an agentic-first software engineer. I build full-stack TypeScript, React and Node systems, and I spend my days figuring out how engineering teams can hand real work to AI coding agents without losing control of quality.

I've worked fully remote for six years, including on large federal contracts. Today I ship production AI features, and I use multi-agent workflows every day.

#### Featured projects

**[Agent Forge](https://github.com/Brian-Coding/Agent-Forge)** is a harness for supervising parallel coding agents (Claude Code and Codex) as a daily workflow. It gives each task its own workspace, real terminals, preview ports, git status and usage tracking, and it keeps a human in charge of review. You can try the full demo without an AI account.

**[AI-UI-Atlas](https://github.com/Brian-Coding/AI-UI-Atlas)** handles AI-driven browser QA with guardrails. It maps an app, tests a user goal, and only passes a verdict the harness can back with captured evidence. A planted-bug eval is published in the repo, including its false-positive rate.

#### What I care about

- Making AI agents dependable teammates through clear task boundaries, real verification, and honest failure modes.
- Helping existing teams adopt AI-centered workflows step by step instead of all at once.
- Measured claims: if a README says it works, there's a test or an eval behind it.
